## 报告判定

所有必需 C ID 必须出现且 PASS；报告缺失、未执行、超时、失败、恢复失败均阻止 `automatic_passed`。A 层模拟核心阶段的真实平台 SKIP 由 B 补充；B 核心能力 SKIP 明确列出。构建摘要、源码状态、面板 SHA 固定并留存。失败有截图/trace/ANSI、结构化报告与客机归档。

H 记录必须匹配本轮二进制摘要及固定环境，并提供六项实际体验证据，才可得到 `accepted_current_scope`。未接入 Mac 时自动通过不等于总体已验收。

## 仍需独立证据的范围

- 公网订阅、实际远程代理、第三方故障及重连：需专用受控目标/凭据；默认 VM 外连被阻断，离线通过不能替代。
- 在线核心/Geo/面板升级及不同版本：需明确源版本、目标版本与联网轮次；当前固定资产部署和失败缓存测试只覆盖现有固定版本。
- macOS/Windows 原生安装、服务、权限、系统代理及剪贴板：需相应 OS 或 CI；从 Mac 远程进入 Linux VM 只验证远程交互。
- 任意规模、任意配置或无限运行时间：不在有限测试的证明范围内，报告必须写明实际规模与时长。

这些测试在具备目标/平台后应尽可能自动运行；缺少条件标记待验证，不转成一长串手工操作，也不算 PASS。
