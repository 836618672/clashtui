## 供总入口读取的 JSON

二进制摘要从同轮 `target/acceptance/<时间>/binary-sha256.txt` 复制，不能用提交号代替。每项 evidence 写实际观察与截图/记录路径；不要只填“已通过”。浏览器与终端必须写版本。以下是未执行模板，不能作为通过证据：

```json
{
  "binary_sha256": "填写实际摘要",
  "core_version": "1.19.24",
  "dashboard": "builtin-vue",
  "browser": "填写 Mac 系统与浏览器版本/范围",
  "terminal": "填写终端版本、TERM、尺寸",
  "checks": {
    "H01": {"status": "not_run", "evidence": ""},
    "H02": {"status": "not_run", "evidence": ""},
    "H03": {"status": "not_run", "evidence": ""},
    "H04": {"status": "not_run", "evidence": ""},
    "H05": {"status": "not_run", "evidence": ""},
    "H06": {"status": "not_run", "evidence": ""}
  }
}
```

仅实际通过才改成 `passed` 并补证据。总入口拒绝摘要不符、缺少环境或 H 证据的记录。它只能校验记录结构与匹配条件，不能替代人对真实观察负责。
