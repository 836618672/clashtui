# Vue、TUI 与 CLI 测试操作指南

更新：2026-10-03。现在只使用内置 Vue 页面。业务测试在 mini PC 的隔离 VM 自动执行；Mac 仅补 H01–H06 的实际体验。迁移前的 MetaCubeXD 操作步骤已退出当前方案。

## 1. 自动与人工的边界

先阅读[总方案](README.md)与[覆盖契约](acceptance_coverage_zh.md)。构建、接口、三端回读、修订冲突、失败恢复、服务操作、DNS/TUN、日志与断线重连由自动测试验证。人工不重复 M01–M30。公网 UDP、其他核心版本与原生 macOS/Windows 仍有各自验证范围。

## 2. mini PC 准备最新环境

自动回归会重置测试磁盘，Mac 会话应在自动回归结束后开始。用户原虚拟机已退休，目前只启动最新面板的测试 VM。

```bash
cd /home/yulinye/clashtui
bash scripts/vm.sh status
bash scripts/vm.sh tunnel
bash scripts/vm.sh check
bash scripts/prepare-human.sh
```

`check` 应报告 guest=clashtui-test、两个服务 active、baseline、TUN/DNS false、外连阻断以及内置页面摘要。`prepare-human.sh` 只准备未激活的剪贴板订阅，随后停止夹具服务器。用于 H05 的 `human-editor` 配置与 vi 编辑命令由本轮人工准备提供。

### 真实订阅下载的联网模式

默认自动测试客机禁止外连，不适合下载公网订阅。当前人工测试环境已开启客机外连，下载超时设为 30 秒；检查使用 `bash scripts/vm.sh check --allow-internet`。宿主与 Mac 的代理、路由、DNS 不需更改。自动回归仍使用默认阻断模式，两个模式的结果分别记录。

需要切换模式时，先退出客机 TUI/编辑器，停止再启动同一 VM（不执行 reset）：

```bash
bash scripts/vm.sh stop
bash scripts/vm.sh start --internet
bash scripts/vm.sh wait --seconds 60
bash scripts/vm.sh tunnel
bash scripts/vm.sh check --allow-internet
```

添加订阅时必须填写配置名称，例如“日常使用”；名称支持中文。页面会清理名称/URL 首尾空格，提示非法或重复名称。激活会准备资源、校验配置、让 Mihomo 重新加载并回读确认，成功后才更新“使用中”标记；失败会回退原配置，任务结果包含原因。首次准备地理数据库可能需要联网下载。下载超时表示运行管理服务的客机未及时取得订阅响应；浏览器自身能访问该地址不代表客机能访问。普通 HTTPS 可达也不能替代对具体订阅地址的验证。

### 2.2 管理令牌

在 mini PC 的终端执行以下命令读取测试管理令牌。只填写 39091 页面的管理令牌；无需核心 secret。

```bash
bash scripts/vm.sh ssh 'cat /home/tester/clashtui-test/config/management-token'
```

令牌不写入 URL、共享报告或截图。管理令牌被拒绝时检查首尾空白和目标 VM；不要修改宿主的核心凭据。

## 3. Mac 连接

Mac Terminal 保持以下 SSH 会话运行。只转发管理端口，不转发代理流量；无需改变 Mac 代理、DNS 或路由。

```bash
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=15 \
  -L 127.0.0.1:39091:127.0.0.1:29091 yulinye@192.168.2.106
```

打开 `http://127.0.0.1:39091/`，必要时强制刷新清除旧页面。连接前只有认证界面，侧栏业务导航隐藏。填写管理令牌，点击连接或按 Enter；成功后可访问总览、订阅、模板、节点、Provider、规则、连接、日志、设置和服务。

旧的 39090/ui 入口已移除。正在运行的旧 SSH 隧道可以结束后重建为以上命令。端口占用时先确认是哪一个自己的隧道进程，避免误停其他工作。

## 4. H01：显示

登录后依次查看总览、订阅、节点、连接、日志和设置。将窗口调整为约 1440、1024、768，另用窄窗口观察侧栏横向导航。核对中文、长名称、卡片、表格、图表和操作结果弹窗可读，不互相遮挡；表格可在自身区域滚动。空连接/日志和静止流量不是错误：空闲核心可以没有活动连接或新日志。

打开某个配置的预览/详情，检查结果弹窗可滚动、关闭按钮可见。记录浏览器版本、各尺寸和实际观察；若声明支持 Safari，另在 Safari 做代表路径，不沿用 Chrome 结果。

## 5. H02：鼠标与焦点

订阅页找到未激活 `human-editor`，点击编辑文件；在末尾输入 `# unsaved human check`，等两次刷新（至少 5 秒），确认内容和输入焦点保留。切到其他路由再回来，草稿应保留。用 Tab/Shift-Tab 在输入、导出、保存之间切换，按钮正常一次点击生效。

点击关闭，先取消丢弃，草稿应仍在；再次关闭并确认丢弃。重新编辑应读到原文件，不含测试注释。结果弹窗内用 Tab 检查焦点保持在弹窗，Esc 关闭后回到原触发控件。把跳焦点、丢字、遮挡和需要反复点击的现象记录为失败。

## 6. H03：提示

退出登录，用错误令牌连接：应显示认证错误，业务导航不可用；输入正确令牌应恢复。认证后修改令牌，应立即锁定页面。

在订阅页尝试删除当前标为“使用中”的配置并确认：应显示当前配置删除保护，该配置保持存在。初始为 baseline，实际订阅测试后可能已切换为其他名称。关闭错误结果后仍可操作其他功能。观察提示是否能明确理解原因，而不是只看自动测试里的状态码。

## 7. H04：终端

Mac 用两层带 TTY 的 SSH 进入客机 TUI：

```bash
ssh -tt yulinye@192.168.2.106 \
  'ssh -tt -i /home/yulinye/clashtui/target/vm/id_ed25519 -p 22222 -o StrictHostKeyChecking=accept-new -o UserKnownHostsFile=/home/yulinye/clashtui/target/vm/known_hosts tester@127.0.0.1 "clashtui --config-dir=/home/tester/clashtui-test/config"'
```

依次切换 1–9 页、打开帮助、滚动长列表。观察 140×40、100×30、80×24 下中文、高亮、边框和输入响应。改变窗口后应恢复布局；按 q 退出，shell 回显与光标正常。这里只验证实际终端体验，不在 Mac 安装代理核心。

## 8. H05：终端编辑器

Files 页选中未激活 `human-editor`，按 E 打开 vi。输入 `G`、`o`，添加注释 `# human editor check`，Esc 后输入 `:wq`。应正常返回 TUI，布局/键盘恢复。再次预览配置确认注释存在；不激活、不修改当前正在使用的配置。

若 vi 没有打开，检查测试配置的 extra.edit_cmd 是否为 `vi %s`，依赖缺失记 BLOCKED；不要以 GUI 编辑器代替。结束时仅删除此注释或重建可丢弃配置。

## 9. H06：浏览器剪贴板

订阅页找到 `c-human-clipboard`，点击复制 URL，把内容粘贴到 Mac 文本编辑器。应准确等于 `http://127.0.0.1:18080/subscription.yaml`。它是测试元数据，服务器不常驻，复制不要求下载订阅。

浏览器禁止复制时，页面应显示失败并提供手动复制结果；不能显示成功。记录浏览器权限提示与实际粘贴结果。远程 TUI 的 Linux 剪贴板不等于 Mac 系统剪贴板。


自动基线应仍是 baseline、TUN/DNS 关闭、两个客机服务运行和外连阻断。若已经进行真实订阅人工测试，使用 `check --allow-internet --profile <当前名称>` 核对实际选择；当前环境为 9yun。宿主未设置代理/路由/DNS，因此不需要“修复宿主网络”。服务或核心不可用时先看客机 journal 和自动报告，失败现场归档后再恢复；不要为解决页面问题修改宿主 Mihomo。
